## 1. La consigne tronquée dans le contrôleur : vrai défaut, corrigé

Ta reproduction hors API est exacte et le défaut est réel : `autoModePrompt` coupait **chaque** demande à 600 caractères, donc l'interdiction de la consigne 2 (offset 1 206 sur 1 583) n'atteignait jamais le contrôleur. Correction (`src/permissions/autoMode.ts`) : la **dernière** demande, celle qui porte les limites de la tâche, va entière jusqu'à 6 000 caractères (tête et queue gardées au-delà, avec un marqueur) ; les précédentes restent à 600, leur idée suffit. Test hors API dans `tests/autoMode.test.ts` avec la consigne 2 réelle : l'interdiction est présente dans le prompt produit ; une demande de 10 000 caractères garde son début et sa fin.

Ce que ça ne fait pas, et tu l'as écrit avant moi : garantir que le classificateur comprendra la limite. C'est une condition nécessaire, pas une isolation.

## 2. Bilan au plafond sans quota : bilan local

D'accord que le bilan au plafond coûte une requête et peut échouer. Ajouté (`src/agent/loop.ts`) : quand un tour s'arrête sur une erreur ou une interruption, une notice nomme les fichiers modifiés pendant le tour (« Files changed this turn: … », d'après les points de reprise). C'est moins qu'un bilan, c'est ce qu'on peut savoir sans le modèle. Test dans `tests/loop.test.ts`.

Vérifications : typage, suite complète, build, commit `0ea62f5`.

## 3. Tes deux distinctions : acceptées telles quelles

- `auto` n'est pas une isolation du système de fichiers : le classificateur peut autoriser ce qu'il a mal compris. D'accord ; c'est pourquoi la règle de pilotage dit « espace isolé quand le vrai dépôt n'est pas nécessaire », et pourquoi je n'ai présenté aucun mode comme sûr.
- Dans la TUI, une permission sans réponse **attend** ; c'est le mode headless qui refuse. Exact, et ça change ce que mon pilote doit faire : détecter la carte de permission dans la capture et répondre « No » explicitement, sinon la session reste suspendue comme l'a fait la fenêtre de bascule de modèle. Je l'ai noté comme condition de pilotage (section 18, §B.5) ; pas encore implémenté dans le pilote, qui n'est pas du code de Fuller.
