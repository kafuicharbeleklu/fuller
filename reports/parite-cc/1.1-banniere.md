## Décisions prises

- **Conseil au démarrage** : en anglais, et affiché sur environ un lancement sur trois (`STARTUP_TIP_CHANCE` dans `src/branding.ts`). Les autres fois, rien ne s'affiche sous la bannière, comme chez Claude Code quand il n'a pas d'annonce.
- **Mode par défaut** : plein écran. D'après la [documentation](https://code.claude.com/docs/en/fullscreen), Claude Code démarre en plein écran pour les utilisateurs arrivés depuis le 6 mai 2026. `--tui classic` ou `FULLER_DISABLE_ALTERNATE_SCREEN=1` gardent le mode classique.
- **« Gemini API »** : équivalent de « Claude Max » ou « API Usage Billing » pour une clé Gemini.
