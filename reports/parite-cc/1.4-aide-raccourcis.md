# 1.4 — Aide des raccourcis (`?`)

Référence : Claude Code 2.1.281, capturé le 24/09/2026 à 100×28, 126×35 et 60×30, sans requête au modèle. À 60×16, Claude Code n'affiche pas l'aide (hauteur insuffisante). Captures dans `captures/1.4-*.json`.

## Claude Code (100×28)

```
────────────────────────────────────────────────────────────────────────────────────────────────────
❯ Try "edit <filepath> to..."
────────────────────────────────────────────────────────────────────────────────────────────────────
  ! for shell mode        double tap esc to clear input      ctrl + shift + _ to undo
  / for commands          shift + tab to auto-accept edits   ctrl + z to suspend
  @ for file paths        ctrl + o for verbose output        ctrl + v to paste images
  /btw for side question  ctrl + t to toggle tasks           alt + p to switch model
                          \⏎ for newline                     ctrl + s to stash prompt
                                                             ctrl + g to edit in $EDITOR
                                                             /keybindings to customize
```

## Fuller après correction

```
───────────────────────────────────────────────────────────────────────────────────────────────────
❯ Try "refactor <filepath> to..."
───────────────────────────────────────────────────────────────────────────────────────────────────
  ! for shell mode        double tap esc to clear input      ctrl + shift + _ to undo
  / for commands          shift + tab to auto-accept edits   ctrl + v to paste images
  @ for file paths        ctrl + o for verbose output        alt + p to switch model
  /btw for side question  ctrl + t to toggle tasks           ctrl + g to edit in $EDITOR
                          \⏎ for newline
```

## Écarts et corrections

| Élément | Claude Code | Fuller avant | Fuller après |
|---|---|---|---|
| Disposition | 3 colonnes grises (colonnes 2, 26, 61 à 100 de large) | 7 lignes écrites en dur, qui se cassent dès 100 colonnes | 3 colonnes aux mêmes positions |
| Largeur étroite (60) | Colonnes rétrécies proportionnellement, retour à la ligne par mot | Lignes coupées au hasard | Même rétrécissement, retour à la ligne par mot |
| Emplacement | À la place du pied de page | Sous la saisie, pied de page toujours visible | À la place du pied de page ; la conversation plein écran rétrécit d'autant |
| Fermeture | `?` ou Échap | Ni `?` ni Échap ne la refermaient à l'écran | `?` ou Échap |
| Contenu | Raccourcis de Claude Code | Liste propre à Fuller (ctrl+r, ctrl+b, ctrl+l…) | Raccourcis de Claude Code qui existent dans Fuller |
| alt+p | Ouvre le choix du modèle | Absent | Ouvre `/model` |

Fichiers : nouveau `src/ui/ShortcutsHelp.tsx`, `src/ui/App.tsx`, `src/ui/InputBox.tsx` (Échap ferme l'aide, alt+p). Tests : nouveau `tests/shortcutsHelp.test.tsx`.

## Retirés de l'aide tant qu'ils n'existent pas dans Fuller

- `ctrl + z to suspend` : dans Fuller, ctrl+z annule (comme ctrl+_). À traiter en 1.9 (raccourcis).
- `ctrl + s to stash prompt` : absent. À traiter en 1.9.
- `/keybindings to customize` : pas de commande. Ajouté à `phase3-a-faire.md`.

## Remarque sur les captures

Juste après le redémarrage de la machine, Fuller a mis plus de 8 s à afficher son premier écran (2 à 5 s ensuite). Les touches envoyées avant étaient renvoyées en écho par le terminal. Les captures attendent maintenant que le pied de page soit affiché (`until:manual mode on`) au lieu d'une durée fixe.
