# 1.7 à 1.9 — Fin de tour, Maj+Tab, raccourcis clavier

1.7 (fin de tour) est traité en 1.6 et 1.8 (Maj+Tab, indicateur de mode) en 1.3. Cette étape couvre les raccourcis.

Référence : Claude Code 2.1.281, capturé le 24/09/2026 à 100×28, sans requête au modèle. ctrl+r n'a pas été capturé : chez Claude Code, il affiche l'historique réel de l'utilisateur. Captures dans `captures/1.9-*.json`. La suspension a été vérifiée en lançant Fuller depuis un `bash` interactif (contrôle des tâches) : `captures/1.9-fuller-ctrlz-bash.json`.

## Écarts et corrections

| Raccourci | Claude Code | Fuller avant | Fuller après |
|---|---|---|---|
| ctrl+s | Met le texte de côté, vide le champ ; « · › stashed » sur la ligne d'indications ; ctrl+s sur champ vide le restitue | Aucun effet | Comme Claude Code (texte, curseur, collages et images restitués) |
| ctrl+z | Suspend le programme : « Claude Code has been suspended. Run `fg` to bring Claude Code back. » et « Note: ctrl + z now suspends Claude Code, ctrl + _ undoes input. » | Annule la dernière saisie | Suspend, même message ; `fg` reprend avec le brouillon intact ; ctrl+_ annule |
| Échap Échap avec du texte | Efface le champ | Efface le champ | Inchangé |
| Échap Échap sans conversation | Aucun effet | Ouvre un menu de retour en arrière vide | Aucun effet (le menu s'ouvre s'il existe un point de reprise) |
| ctrl+t sans tâches | Aucun effet | Aucun effet | Inchangé |
| ctrl+o | Conversation détaillée ; en bas : filet atténué et « Showing detailed transcript · ctrl+o to toggle · ? for shortcuts », « verbose » à droite | En-tête « Transcript viewer · N lines » et deux lignes de raccourcis | Présentation de Claude Code ; `?` affiche les raccourcis de la visionneuse |
| Aide `?` | Liste ctrl+z et ctrl+s | Absents (non implémentés) | Ajoutés |

Détails techniques :

- Suspension : Fuller rend le terminal comme pour l'authentification (`runInTerminal`), affiche le message, s'envoie SIGTSTP et attend SIGCONT. Sans contrôle des tâches (groupe de processus orphelin), le noyau ignore SIGTSTP ; un délai de 300 ms évite alors de rester bloqué.
- `frameWriter.suspend` et `runInTerminal` acceptent un bandeau personnalisé ; l'authentification garde « Authentication in the terminal · Ctrl+C to cancel ».
- La visionneuse (`Pager`) sert aussi à `/diff`, qui prend la même présentation.
