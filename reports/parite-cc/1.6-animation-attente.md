## Écarts et corrections

| Élément | Claude Code | Fuller avant | Fuller après |
|---|---|---|---|
| Symboles | `· ✢ * ✶ ✻ ✽` | `· ✢ ✦ ✶ ✻ ✽` | Ceux de Claude Code |
| Verbe | Couleur de marque, traversé par un reflet plus clair | Couleur accent fixe | Reflet calculé à partir de la couleur d'accent du thème |
| Compteur | Absent à 4 s, `(6s · thinking)` à 6 s | `(esc to interrupt · 1s)` dès la 1re seconde | `(7s · thinking)` à partir de 5 s ; `↓ N tokens` pendant l'écriture |
| « esc to interrupt » | Dans le pied de page | Dans la ligne d'attente | Dans le pied de page |
| Saisie pendant l'attente | Visible, `❯` gris | Masquée avec le pied de page | Visible, `❯` gris |
| Fin de tour | `✻ Churned for 14s · done 3:20 AM`, gris | `✻ Worked for 14s · 0 tool uses` | `✻ <verbe> for 14s · done 3:20 AM`, gris ; verbe tiré d'une liste (Brewed, Churned, Cooked…) |
| Indicateur de contexte | Seulement à partir de 80 % utilisés | Toujours affiché (`Context left until auto-compact: 100%`) | À partir de 80 % utilisés |
| Interruption | `Interrupted · What should Claude do instead?` | `Interrupted · What should Fuller do instead?` | Inchangé (déjà aligné) |

La ligne de fin de tour est maintenant produite par une seule fonction (`turnEndLine` dans `viewerText.ts`), pour le mode classique comme pour le plein écran.

## Pour la phase 2 (rendu de la conversation)

- **Mots coupés** : dans la conversation plein écran, Fuller coupe les lignes en plein mot (`tal` / `l against relentless waves`). Claude Code revient à la ligne entre les mots.
- **En-tête** : Fuller affiche `Conversation · N rows` en haut de la conversation plein écran ; Claude Code n'a pas d'en-tête.
- **Retraits** : les lignes de Fuller commencent en colonne 1 (`❯` utilisateur, ligne d'attente), celles de Claude Code en colonne 0.
- **Message de l'utilisateur** : Claude Code l'affiche sur fond `#373737`, avec un `❯` gris.
- **`⎿`** : suivi de deux espaces chez Claude Code, d'un seul chez Fuller.
- **Erreur 429** : Fuller affiche `API Error (429) · Retrying in 5 seconds… (attempt 4/5)` sur une ligne à part ; à comparer avec Claude Code.
