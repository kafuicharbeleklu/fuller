# 1.3 — Pied de page et ligne d'indications

Référence : Claude Code 2.1.281 (`--permission-mode default`), capturé le 23/09/2026 à 60×16, 100×28 et 126×35, sans requête au modèle. Les symboles d'effort ont été relevés en lançant `claude --effort low|high|xhigh|max`. Captures dans `captures/1.3-*.json` et `captures/1.3b-*.json`.

## Claude Code (100×28)

```
                                                                                ◐ medium · /effort
────────────────────────────────────────────────────────────────────────────────────────────────────
❯ Try "fix lint errors"
────────────────────────────────────────────────────────────────────────────────────────────────────
  ⏸ manual mode on · ? for shortcuts · ← for agents
```

## Fuller après correction

```
                                                                                ◐ medium · /model
───────────────────────────────────────────────────────────────────────────────────────────────────
❯ Try "edit <filepath> to..."
───────────────────────────────────────────────────────────────────────────────────────────────────
  ⏸ manual mode on · ? for shortcuts · /agents for agents
```

## Écarts et corrections

| Situation | Claude Code | Fuller avant | Fuller après |
|---|---|---|---|
| Retrait du pied | 2 espaces | 1 espace | 2 espaces |
| Mode manuel, au repos | `⏸ manual mode on · ? for shortcuts · ← for agents`, gris | `⏵⏵ default mode on (shift+tab to cycle) · /agents for agents`, bleu | `⏸ manual mode on · ? for shortcuts · /agents for agents`, gris |
| Autres modes | `⏵⏵ accept edits on` (`#af87ff`), `⏸ plan mode on` (`#48968c`), puis `(shift+tab to cycle) · ← for agents` en gris | Couleurs `#bb9af7` et `#2ac3de`, sans le lien vers les agents | Couleurs et texte de Claude Code |
| Pendant la saisie | Mode seul (`⏸ manual mode on`) | `enter to send · \⏎ for newline` | Mode seul |
| Partie droite du pied | Rien | `◉ medium · Gemini 3.6 Flash` | Rien (le contexte restant et les tâches de fond restent affichés quand il y en a) |
| Ligne au-dessus de la saisie, au repos | `◐ medium · /effort`, gris, aligné à droite | Absente | `◐ medium · /model` |
| Même ligne, texte sur plusieurs lignes | `ctrl+g to edit in VS Code` | Absente | `ctrl+g to edit in <éditeur>` |
| Même ligne, après ctrl+u, ctrl+k ou ctrl+w | `Ctrl+Y to paste deleted text` tant que le champ n'est pas vide | Absente | Identique |
| Symboles d'effort | low `○`, medium `◐`, high `●`, xhigh `◉`, max `◈` | `◉` pour tous | Ceux de Claude Code (`○` pour minimal, niveau qui n'existe pas chez Claude Code) |
| 60 colonnes | Texte complet | Texte abrégé | Texte complet |

L'éditeur suit maintenant Claude Code : `$VISUAL`, puis `$EDITOR`, puis VS Code s'il est installé, puis `vi`. Avant, Fuller passait directement à `vi`.

La ligne d'indications prend la place de la ligne vide qui précédait la saisie : la hauteur totale ne change pas, et le plein écran garde son budget de lignes.

Fichiers : `src/ui/Footer.tsx` (pied et nouveau composant `PromptHints`), `src/ui/App.tsx`, `src/ui/InputBox.tsx` (états « plusieurs lignes » et « texte supprimé »), `src/ui/externalEditor.ts` (`resolveEditor`, `editorName`), `src/ui/theme.tsx`. Tests : `tests/startupScreen.test.tsx` (pied dans chaque mode, ligne d'indications), `tests/inputParity.test.tsx`, instantanés de `tests/terminalLifecycle.test.tsx`.

## Écarts assumés

- **`/model` au lieu de `/effort`** : Fuller n'a pas de commande `/effort` ; l'effort se règle avec ←/→ dans `/model`. À revoir en phase 3.
- **`/agents for agents` au lieu de `← for agents`** : Fuller n'a pas le panneau d'agents ouvert par ←.
- **Mode auto** (`⏵⏵ auto mode on`, `#ffc107`) : n'existe pas dans Fuller. Maj+Tab y fait le cycle manual → accept edits → plan → bypass.

## Note technique

L'indicateur « plusieurs lignes » était d'abord calculé à partir du texte au moment du rendu. Dans `InputBox`, l'effet qui prévient l'application ne se relançait pas quand cette valeur changeait. Le problème se reproduisait en test et dans un vrai terminal, mais pas dans un composant minimal. C'est maintenant un état React, mis à jour à chaque modification du texte. La cause exacte n'est pas identifiée.
