# Fuller égale Claude Code ; restent les finitions

À HEAD `4c544ba`, Fuller reproduit déjà presque toute la structure de l'interface de Claude Code 2.1.282 : éditeur de saisie readline, plein écran virtualisé par défaut, lecteur Ctrl+O façon `less`, panneau `/diff`, cartes de permission, dialogues à onglets et cycle des modes. Sa suite de tests passe entièrement (**66 fichiers, 509 tests**). Les deux dernières semaines de Claude Code (2.1.270 à 2.1.283) n'ont apporté aucune grande fonction, seulement du polissage de listes, de souris et de performance : l'écart restant est une traîne de détails, pas un retard de structure. Le meilleur rapport valeur/effort tient en **huit gains rapides**, vérifiés dans la doc ou le binaire. Il s'agit surtout de filets de sécurité et de raccourcis : `/tasks` qui ouvre vraiment une tâche, Ctrl+D à double appui, Échap Échap qui garde le brouillon, l'option « switch to auto mode » sur les prompts Bash et dans le dialogue de plan, la pause du mode auto après une série de refus, et l'heure dans Ctrl+O. Viennent ensuite **cinq chantiers moyens** : afficher la réflexion de Gemini, ajouter l'en-tête collant et le compteur de nouveaux messages en plein écran, changer de renderer avec `/tui` en cours de session, adopter le format `keybindings.json` de Claude Code et rendre `/mcp` actif. Deux routes coûteuses sont des impasses pour une petite équipe : le mode vim et la sélection de texte dans l'application, que Claude Code lui-même n'a pas stabilisée. Fuller ne contient aucune des fonctions qu'Anthropic a retirées ; c'est à garder ainsi. Enfin, huit petits défauts internes se corrigent en une journée, et une douzaine d'écrans doivent être capturés sur le vrai binaire avant qu'on les code.

## Fuller reproduit déjà l'essentiel de Claude Code 2.1.282

La référence est **Claude Code 2.1.282**, version `latest` sur npm depuis le 24/09/2026. La **2.1.283** est sortie le 25/09 sur le canal `next` ([registre npm](https://registry.npmjs.org/@anthropic-ai/claude-code)). Les faits Claude Code viennent de trois sources : la doc officielle téléchargée le 25/09, le CHANGELOG, et les chaînes extraites du binaire 2.1.282 installé sur cette machine ([binaire 2.1.282](file:///home/administrator/.local/share/claude/versions/2.1.282)). Les faits Fuller viennent de la lecture du code à `4c544ba`, complétée par des vérifications ciblées pour ce rapport. Le binaire donne les libellés exacts, mais sa mise en page n'est que déduite d'un code minifié. Chaque fois qu'un point dépend de la disposition à l'écran, le rapport le marque « capture requise ».

La zone de saisie couvre le clavier readline que Claude Code a généralisé en 2.1.261 : Ctrl+A/E/K/U/W/Y, Alt+B/F/D avec segmentation Unicode, Ctrl+_ pour annuler, Ctrl+Z pour suspendre ([interactive-mode](https://code.claude.com/docs/en/interactive-mode#text-editing) ; [InputBox.tsx](../src/ui/InputBox.tsx)). Les collages se replient aux mêmes seuils que chez Claude Code, **plus de 3 lignes ou plus de 800 caractères**, et les caractères invisibles sont retirés à l'envoi ([terminal-config](https://code.claude.com/docs/en/terminal-config#paste-large-content)). Le menu `/` complète au milieu du prompt comme le décrit la doc de 2.1.265 : texte fantôme `+N` en classique, liste sans sélection initiale en plein écran. Ctrl+R existe dans ses deux présentations. En classique, c'est une recherche en ligne où Entrée exécute ; en plein écran, c'est un dialogue où Ctrl+S change la portée et où Entrée charge le prompt sans l'exécuter ([interactive-mode](https://code.claude.com/docs/en/interactive-mode#reverse-search-with-ctrl%2Br) ; [HistorySearch.tsx](../src/ui/HistorySearch.tsx)). Les messages en file se reprennent avec ↑, placés devant le brouillon, et partent tout de suite avec Ctrl+Entrée ou Ctrl+X Ctrl+S. Complètent l'ensemble : le mode `!`, la mise de côté avec Ctrl+S, l'éditeur externe avec Ctrl+G, le double Échap qui ouvre `/rewind`, Ctrl+B qui passe un Bash en arrière-plan, et Ctrl+L qui redessine sans rien effacer.

Pour le rendu, Fuller suit le choix qu'Anthropic a fait pour ses nouveaux utilisateurs depuis le **6 mai 2026** : plein écran par défaut sur l'écran alternatif, conversation virtualisée, PgUp/PgDn par demi-page, molette de 3 lignes, Ctrl+Home/End et « Jump to bottom » ([fullscreen](https://code.claude.com/docs/en/fullscreen#fullscreen-by-default) ; [FullscreenTranscript.tsx](../src/ui/FullscreenTranscript.tsx)). Le lecteur Ctrl+O a la navigation façon `less` (`/`, `n`/`N`, `{`/`}`, Ctrl+U/D), plus `[` pour copier vers le scrollback natif et `v` pour ouvrir l'éditeur. Ce sont justement les manques reprochés à Claude Code dans l'issue sur la perte du scrollback ([Pager.tsx](../src/ui/Pager.tsx) ; [issue #42670](https://github.com/anthropics/claude-code/issues/42670)). Le mode classique garde le scrollback natif et la sortie synchronisée DEC 2026. Le panneau `/diff` suit la doc point par point : 110 colonnes minimum, ouverture automatique à 144, ✕, clic vers le fichier, Ctrl+X B pour changer de base, fichiers de test masqués, sélection de lignes jointe au prompt suivant. La visionneuse classique a une vue Current et des vues par tour ([interactive-mode](https://code.claude.com/docs/en/interactive-mode#review-changes-with-%2Fdiff) ; [DiffPanel.tsx](../src/ui/DiffPanel.tsx)). D'autres éléments sont alignés : les replis `… +N lines (ctrl+o to expand)`, la ligne de fin de tour dont le verbe est choisi par hachage comme dans le binaire, les libellés de mode du pied de page, et la status line, qui reçoit le même JSON avec un anti-rebond de 300 ms ([statusline](https://code.claude.com/docs/en/statusline) ; [viewerText.ts](../src/ui/viewerText.ts)). La liste des verbes diffère (Mulled, Pondered, Simmered chez Fuller) ; c'est un choix d'identité, pas un écart.

Les dialogues principaux ont tous un équivalent comparé à une capture. Settings a quatre onglets, Status, Config, Usage et Stats, soit la structure exacte du binaire. S'y ajoutent Help à trois onglets, Permissions à six onglets, le sélecteur de modèle (←/→ pour l'effort, `s` pour la session), la reprise de session, Rewind avec ses six actions aux libellés de la doc, la vue des agents, `/btw`, la grille `/context` et l'export. L'approbation des serveurs MCP a été comparée au binaire 2.1.282, et le dialogue de confiance présélectionne « No, exit » ([checkpointing](https://code.claude.com/docs/en/checkpointing#rewind-and-summarize) ; [InfoDialogs.tsx](../src/ui/InfoDialogs.tsx)). La carte de permission a les titres par outil et le commentaire sur Tab ; un refus sans commentaire arrête le tour ([permissions](https://code.claude.com/docs/en/permissions)). Ses libellés sont déjà ceux de 2.1.282. **« Yes, and switch to accept edits (…) for this session (shift+tab) »** remplace l'ancien « allow all edits during this session », qui a disparu du binaire. « Yes, and don’t ask again for: <commande> » garde l'apostrophe typographique ([rules.ts](../src/permissions/rules.ts)). Enfin, `/agents` n'affiche qu'un message de renvoi : c'est exactement le comportement de Claude Code depuis la suppression de son assistant.

L'inventaire de Fuller classait plusieurs points comme « propres à Fuller » ou « non vérifiés ». Rapprochés des notes sur Claude Code, ce sont en fait des points de parité. Ctrl+E dans le lecteur classique correspond à `transcript:toggleShowAll` ([keybindings](https://code.claude.com/docs/en/keybindings#transcript-actions)). `/checkup` est un alias de `/doctor` dans le registre du binaire. `--screen-reader` répond à `--ax-screen-reader` ([accessibility](https://code.claude.com/docs/en/accessibility#turn-on-screen-reader-mode)). `/skills` et `/stats` existent chez Claude Code, et le second ouvre l'onglet Stats de `/usage`. « Reply after ! commands » reproduit `respondToBashCommands` ([commands](https://code.claude.com/docs/en/commands) ; [interactive-mode](https://code.claude.com/docs/en/interactive-mode#shell-mode-with-prefix)). À l'inverse, une note tirée du binaire plaçait l'onglet Workspace avant Auto mode dans `/permissions`. La capture réelle du 24/09 montre **« Recently denied · Allow · Ask · Deny · Auto mode · Workspace »**, qui est l'ordre de Fuller ([3d-reprise-et-historique.md](parite-cc/3d-reprise-et-historique.md)). L'ordre des appels dans un code minifié reste une inférence ; c'est la capture qui tranche.

### Deux impasses et deux paris conditionnels

**Le mode vim est une impasse pour une petite équipe, sauf si quelqu'un le demande.** Chez Claude Code, il couvre INSERT, NORMAL, VISUAL et VISUAL LINE, les opérateurs, les objets texte, les comptes, `.` et le remappage `jj` vers Échap. 2.1.281 et 2.1.282 corrigent encore des bogues de comptes et de position du curseur ([interactive-mode](https://code.claude.com/docs/en/interactive-mode#vim-editor-mode) ; [CHANGELOG 2.1.282](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21282)). C'est une semaine de travail, suivie d'une longue traîne de corrections. S'il se fait, ce sera par `/config` → Editor mode, jamais par une commande `/vim`.

**La sélection de texte dans l'application est la seconde impasse.** Claude Code copie à la sélection, gère le double et le triple clic, étend la sélection avec Maj+flèches et fait copier Ctrl+C quand une sélection existe ([fullscreen](https://code.claude.com/docs/en/fullscreen#use-the-mouse)). Pourtant, sa méta-issue recense **42 issues ouvertes** sur le copier-coller et conclut que « the TUI renders for visual appearance, not for selection/copy fidelity » ([#81472](https://github.com/anthropics/claude-code/issues/81472)). La voie pratique est déjà presque en place. Selon la doc, maintenir Maj donne la sélection native dans la plupart des terminaux ([fullscreen](https://code.claude.com/docs/en/fullscreen#keep-native-text-selection)) ; il faut le vérifier une fois sous VTE, puis l'indiquer à l'écran. Pour le reste, on dispose de `[`, `/copy`, `/export` et, demain, `/tui default`.

**Le protocole clavier kitty ne vaut que selon le terminal.** Même Claude Code n'a pas Maj+Entrée sous gnome-terminal ni dans les IDE JetBrains. Il ne l'obtient sans réglage que sur les terminaux qui répondent à la requête kitty, comme foot ou Alacritty 0.16+ ([terminal-config](https://code.claude.com/docs/en/terminal-config#enter-multiline-prompts)). Son activation a d'ailleurs cassé F1/F2/F4, Suppr et Alt+flèches sur plusieurs terminaux entre 2.1.247 et 2.1.269 ([CHANGELOG 2.1.269](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21269)). Si l'équipe travaille sous VTE, comme le suggère le script de redimensionnement du dépôt, il n'y a rien à gagner. Ctrl+J, `\`+Entrée et Alt+Entrée marchent déjà. **Les listes cliquables, barres de défilement et teintes au survol** sont le polissage de 2.1.271 à 2.1.283. Après des plaintes sur les clics accidentels ([#70539](https://github.com/anthropics/claude-code/issues/70539), ~92 réactions ; [#70622](https://github.com/anthropics/claude-code/issues/70622), ~85), Claude Code a dû ajouter `CLAUDE_CODE_DISABLE_MOUSE_CLICKS`. Si Fuller les fait, il doit livrer d'emblée un interrupteur équivalent. La dictée vocale, la correction orthographique, les emoji `:shortcode:` et les suggestions de prompt générées par le modèle, qui consommeraient du quota Gemini, ne méritent pas l'effort.

### Capturer avant de coder

Une douzaine d'éléments exigent une capture réelle avant l'implémentation, parce que seul leur texte, voire rien, est connu. Ce sont : le libellé de confirmation de Ctrl+D, le prompt Bash avec son astuce du mode auto, le dialogue de plan, le message de pause du mode auto, le format de l'heure dans Ctrl+O, le rendu replié de la réflexion, l'en-tête collant et le compteur de messages, le menu d'un serveur MCP, le sélecteur de `/copy`, la vue `/focus`, la file grisée, le panneau de tâches et le libellé de contexte du pied de page (défaut n°7). S'y ajoutent les libellés de la section 20 du panneau `/diff`, faits d'après la doc et jamais capturés ([Note_de_passation_Claude.md](Note_de_passation_Claude.md)). L'outil existe déjà : `scripts/parity-capture.py claude:<args> <cols>x<rows> <out.json> [étapes]` ([parity-capture.py](../scripts/parity-capture.py)) a produit les 149 fichiers de capture de `reports/parite-cc/captures/`, pour Claude Code comme pour Fuller. Il faut garder les tailles déjà utilisées (60×16, 100×28, 126×35) et lancer `claude` **seul, jamais en parallèle d'une autre session** : des sessions simultanées désactivent son plein écran. Le dialogue de plan, le prompt Bash et la réflexion exigent un vrai tour du côté de Claude Code. Enfin, Windows n'a jamais été vérifié, puisque la CI ne tourne que sur `ubuntu-latest`.

Il y a aussi un piège en sens inverse : **`/output-style` n'est pas retiré**. Déprécié en 2.1.73, il a été **réintroduit en 2.1.269** avec les styles Default, Proactive, Concise, Explanatory et Learning ([output-styles](https://code.claude.com/docs/en/output-styles) ; [CHANGELOG 2.1.269](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21269)). C'est donc un écart réel, de faible valeur, et non une consigne d'abstention. Deux déplacements de touches confirment les choix de Fuller. L'arrêt des agents est passé de Ctrl+F à Ctrl+X Ctrl+K « to stop shadowing readline forward-char », et la bascule de réflexion de Tab à Alt+T « to avoid accidental triggers » ([interactive-mode](https://code.claude.com/docs/en/interactive-mode#general-controls) ; [changelog](https://code.claude.com/docs/en/changelog)). Fuller garde Ctrl+F pour avancer d'un caractère et Tab pour la complétion, ce qui est juste. Une règle pratique en découle, déduite de ces allers-retours : **attendre une ou deux versions avant de recopier un changement d'interaction récent**.

## La couche Gemini de Fuller n'est pas un écart

Fuller ajoute une gestion complète du fournisseur, qu'un comparatif ne doit pas compter comme divergence. On y trouve plusieurs clés `GEMINI_API_KEYS` avec rotation silencieuse, une clé refusée écartée 24 h, et une attente affichée sur la limite par minute (« Rate limit reached · continuing in 34s »). S'y ajoutent une chaîne de modèles de repli réglable (ask, auto ou off), `fuller --check-keys` et `--list-models`. La fenêtre de quota distingue trois cas : limite atteinte, surcharge et conversation trop longue ; elle propose Keep trying, Switch to Y ou Stop. Une barre de quota s'affiche dans le pied de page et une ligne dans `/status` ([README.md](../README.md) ; [QuotaDialog.tsx](../src/ui/QuotaDialog.tsx) ; [Footer.tsx](../src/ui/Footer.tsx)). Claude Code a des équivalents d'esprit, « Usage limit reached · continuing automatically at 3:45pm · esc to cancel » et la commande cachée `/rate-limit-options`, mais pour les forfaits Anthropic ([interactive-mode](https://code.claude.com/docs/en/interactive-mode) ; [commands](https://code.claude.com/docs/en/commands)). Les versions de Fuller répondent aux quotas de Gemini. Il ne faut pas les réécrire sur les libellés de Claude Code.

D'autres éléments sont aussi propres à Fuller : le niveau d'effort `minimal`, le sélecteur alimenté par l'API ListModels et filtré sur les modèles gratuits, la ligne « Cached prompt » du cache implicite dans Usage, et des garde-fous d'agent réglables dans `/config` (Check work before finishing, Review changes, Clear old tool output, Learned memory avec `/learn`). S'y ajoutent les commandes `/learn`, `/checkpoints`, `/sessions`, `/about`, `/mode`, `/accept-edits` et `/verbose`, les thèmes monokai, ocean et autres, et Ctrl+Suppr dans `/resume`. Claude Code, lui, ne documente aucune suppression depuis ce sélecteur ([sessions](https://code.claude.com/docs/en/sessions)). La limite de la status line vient de la même logique : `cost.total_cost_usd` vaut toujours 0 ([useStatusLine.ts](../src/ui/useStatusLine.ts)). C'est acceptable sur l'offre gratuite. Il faudra le calculer si l'équipe passe durablement à la facturation Tier 1, évoquée dans la note de passation.

À l'inverse, un pan entier de Claude Code dépend du compte ou des produits Anthropic et n'a pas à être rattrapé. Cela comprend les montants en dollars et les barres de forfait de `/usage`, `/login`, `/fast` et Alt+O, `/upgrade`, `/passes`, `/mobile`, `/desktop`, `/teleport`, `/remote-control`, `/chrome`, `/install-github-app`, `/radio`, `/stickers` et `/powerup`, les sessions cloud, les équipes d'agents, le marketplace de plugins et l'intégration IDE ([commands](https://code.claude.com/docs/en/commands)). Les six niveaux d'effort de Claude ne s'appliquent pas non plus : Gemini expose minimal, low, medium et high.

## Conclusion

La parité n'est plus une question de fonctions mais de tri. La structure de l'interface est au niveau, et Claude Code bouge désormais surtout par petites retouches, dont certaines sont annulées trois semaines plus tard. Copier la dernière version au plus près coûte donc plus que ça ne rapporte. Deux choses rapportent davantage : aligner Fuller sur les **contrats stables** de Claude Code (format de `keybindings.json`, JSON de la status line, libellés de permission tirés du binaire, qui permettent de réutiliser des fichiers et des habitudes existants), et fermer les petits trous de sécurité qu'une journée suffit à corriger. La différence de fournisseur fixe la seule vraie divergence stratégique. Claude Code fait du mode auto le chemin par défaut ; pour Fuller, chaque décision de ce mode coûte un appel Gemini. Le bon réglage est de rendre le mode auto accessible au bon moment sans l'imposer.

La discipline de capture est la seconde leçon. Lu dans le code minifié, le binaire a suggéré un ordre d'onglets que la capture réelle a contredit. Tout changement de libellé ou de disposition doit donc passer par `parity-capture.py`, avec un `claude` lancé seul, avant d'entrer dans le code. Une douzaine d'écrans attendent cette étape, et c'est elle, plus que l'effort de développement, qui fixera le rythme des prochaines semaines.
